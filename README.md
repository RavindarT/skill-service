# skill-service

Independent Java 17 / Spring Boot 3.5.7 / Maven CRUD API using PostgreSQL, Spring Data JPA, Flyway, request validation and GitHub Actions CI.

**Local port:** 8082  |  **PostgreSQL database:** `skills_db`  |  **Path:** `/api/skills`

## Run

From the parent `skillsalary-microservices` directory, start databases with `docker compose up -d`.
Then from this service directory run:

```bash
mvn clean verify
mvn spring-boot:run
```

Migrations create the table on app startup. `DB_URL`, `DB_USER`, `DB_PASSWORD` and `SERVER_PORT` may override defaults.

## CRUD

- `POST /api/skills` (201)
- `GET /api/skills` (200)
- `GET /api/skills/{id}` (200 / 404)
- `PUT /api/skills/{id}` (200 / 404)
- `DELETE /api/skills/{id}` (204 / 404)
- `GET /actuator/health`

Example POST JSON:

```json
{
  "desc": "Java Developer"
}
```

For POST, omit autogenerated numeric IDs. For relationship services, supply both ID fields; together they form the composite primary key. `desc` is the JSON property; it is stored as `description` in PostgreSQL to avoid SQL keyword conflicts.

**Important:** Cross-service employee/skill/job IDs are not verified against other databases yet. Implement HTTP/event-backed validation later. No DB credentials should be committed for nonlocal deployments.
